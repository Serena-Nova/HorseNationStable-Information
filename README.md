## Zetten op GitHub Pages
1. Maak een nieuwe repository aan (bijv. `Horse-kladblok`) op je `serena-nova` account.
2. Upload `index.html` en `.nojekyll` naar de `main` branch (root van de repo).
3. Ga naar **Settings → Pages**, kies branch `main` / map `/ (root)`, sla op.
4. Na een minuutje staat je app op `https://serena-nova.github.io/Horse-kladblok/`.

## Werking
- Alle wijzigingen worden automatisch bewaard in de browser (localStorage) — geen account of internet nodig na het laden.
- Onderaan: **Exporteer JSON** om een back-up te downloaden, **Importeer JSON** om die back-up terug te zetten (bijvoorbeeld op een ander toestel).
- Je huidige kladblok-lijst staat er al in als startpunt.
